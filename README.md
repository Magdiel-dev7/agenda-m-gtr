# 📅 Agenda M-GTR

Sistema de agenda pessoal desenvolvido para organização de compromissos diários, com foco em praticidade e persistência de dados.

Link do projeto: [https://magdiel-dev7.github.io/agenda-m-gtr/](https://magdiel-dev7.github.io/agenda-m-gtr/)

---

## 🚀 Funcionalidades

- **CRUD Completo:** Adicionar, visualizar, editar e excluir compromissos.
- **Gestão de Estado:** Marcar tarefas como concluídas ou pendentes.
- **Filtros Inteligentes:** Visualização segmentada por status da tarefa.
- **Persistência:** Os dados são salvos no navegador do usuário, garantindo que as informações não se percam ao fechar a aba.

## 💻 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da interface.
- **CSS3:** Estilização moderna e layout responsivo.
- **JavaScript (ES6+):** Lógica de programação, manipulação dinâmica do DOM e controle de eventos.
- **LocalStorage:** Armazenamento de dados persistentes no lado do cliente.

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o propósito de consolidar conhecimentos fundamentais de desenvolvimento Web Front-end, focando na manipulação de arrays de objetos, tratamento de strings e armazenamento local.
