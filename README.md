# agenda-m-gtr
Agenda M-GTR

Sistema de agenda pessoal para organização de compromissos, desenvolvido com HTML, CSS e JavaScript.

🚀 Funcionalidades
- Adicionar compromissos
- Editar tarefas
- Excluir registros
- Marcar como concluído
- Filtrar pendentes e concluídos
- Armazenamento local com localStorage

💻 Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- LocalStorage

🎯 Objetivo do projeto
Praticar lógica de programação, manipulação do DOM, organização de código e desenvolvimento de interfaces funcionais.
